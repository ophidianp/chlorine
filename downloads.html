Three steps to a smoother session.

  1. Install Fabric. Choose the Fabric Loader for the same Minecraft version as the Chlorine download.
  2. Check the download box. Install the dependencies shown with your selected Minecraft version before launching Fabric.
  3. Drop in the JAR. Place the Chlorine file in your Minecraft instance's mods folder and launch Fabric.

Java requirement: Java 25 or newer. Fabric Loader requirements are listed in each release's GitHub metadata.
