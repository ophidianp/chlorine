GETTING STARTED

Three steps
to a smoother session.

01

Install Fabric

Choose the Fabric Loader for the same Minecraft version as the Chlorine download.

02

Add dependencies

For Minecraft 26.3, install Fabric API, Cloth Config API, and Sodium 0.9.2 or newer. Mod Menu is optional for an in-game config button.

03

Drop in the JAR

Place the Chlorine file in your Minecraft instance's mods folder and launch Fabric.

Requirements: Java 25 or newer. Fabric Loader 0.19.5+ and Sodium 0.9.2+ for Minecraft 26.3. Cloth Config API is required for both versions; Mod Menu is optional.
