# Isotope

**Run Fabric mods built for a different Minecraft 26.x version.**

An isotope is the same element with a different mass number. Isotope gives you
the same mod with a different version number: it rewrites a mod made for
another 26.x release so it links against the Minecraft you are actually running.

Status: early development. See the sections below once the first build lands.
