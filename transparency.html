Transparency

Made with Claude. Said plainly.

Chlorine was made with Claude, Anthropic's AI, working through Claude Code. I chose what to build, tested it, and decided what shipped. This page says which parts were whose, and how much of it is still unproven.

WHO WROTE IT

The code came from AI

The mod, its settings screen, this website and its copy were written by AI. The project's README also lists ChatGPT Codex, GitHub Copilot and Nemotron 3.5 super VL as tools used along the way. The chat log below is the Claude Code session from 1.0.5 onward, written by Claude Opus 5.5 and Claude Sonnet 5.5.

WHAT I DID

One person steering

I set the direction, picked which ideas to build, and sent the screenshots. I tested the builds in the game on a Ryzen 5 5500 with a Radeon RX 6500 XT, and decided what to keep, rename and release. I attach each jar and publish each release myself. Claude can't see the game, so tuning followed what I reported.

NOT PROVEN

What is still unverified

The newest changes (1.0.6 to 1.0.8) have no controlled frame-time benchmark. The numbers on the Benchmarks page are sampled readings from recordings on one PC. The demos on this site illustrate the ideas, they are not measurements.

Checked and not checked

What has been tested, and what hasn't.

These are the claims I can stand behind today, and the ones I can't yet.

A

Builds compile and load

Releases are built from a clean state. The 1.0.7 Sodium changes were run in a real client with Sodium 0.9.2, and the patched code was inspected to confirm the hooks landed.

CHECKED
B

Only one setup was played

Recent testing was on one PC and one version, Minecraft 26.3 with Sodium 0.9.2. Other hardware, other versions and large modpacks have not been tested.

LIMITED
C

Frame-rate gains are unmeasured

The frame smoothing and Sodium changes are meant to soften hitches. No capture tool such as CapFrameX has been used to measure 1% lows before and after, so no gain is claimed.

UNPROVEN
D

The memory governor is new

It compiles and ships in 1.0.8, but it has not been played over long sessions or benchmarked. It can't replace Java's garbage collector, which your launcher's JVM flags control.

NEW
E

Sodium patches can switch off

They target Sodium's internal code, so a Sodium update can make them stop applying. They are written to skip quietly rather than crash, but that means a future update could silently remove their effect.

FRAGILE

Where it comes from

Built on other people's work.

Chlorine is not a fork. It is a separate project that leans on these mods and tools, and it is not affiliated with any of them.

A

Fabric

It runs on Fabric Loader and Fabric API, with Mojang's official mappings, and uses Mixin hooks to change game behavior.

PLATFORM
B

Cloth Config and Mod Menu

The in-game settings screen is built with Cloth Config, which is required. Mod Menu is optional and only adds a Config button to the mod list.

LIBRARIES
C

Sodium

From 1.0.3 on, Chlorine requires Sodium 0.9.2 or newer and hooks into its chunk renderer. Claude read the compiled Sodium jar to find the hook points. No Sodium source code is copied into this repository, and Sodium is not bundled: you install it yourself. Sodium is licensed under PolyForm Shield 1.0.0 by CaffeineMC.

REQUIRED
D

Companion mods

It is designed to coexist with Lithium, FerriteCore, EntityCulling, ImmediatelyFast and Iris. None of them is required, and none of their code is in Chlorine.
